Linear 凭证提取与自动刷新扩展（Chrome / Edge）v1.1

首次安装或升级：
1. 解压 ZIP 到固定目录。升级时用新版文件替换原目录，并在扩展管理页点击重新加载。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 将扩展固定到工具栏。升级增加了 scripting 权限，用于在 Linear 页面执行只读登录检查。

手动提取：
在同一浏览器登录 Linear 并进入目标工作区，保存未提交内容后点击“一键提取并下载 JSON”。
扩展刷新当前标签页，最多等待 90 秒，捕获一条包含完整身份与 Cookie 的请求并生成 JSON。
若弹窗关闭，可在 5 分钟内重新打开扩展下载。到网关的账户管理页导入文件。

自动刷新：
1. 先导入账号，用管理员账号密码登录网关，在该账号下点击“配对自动刷新”。
2. 在已登录同一账号、同一工作区的 Linear 标签页打开扩展。
3. 填写网关地址（例如 http://127.0.0.1:8089，不含 /v1）和后台的一次性配对码。
4. 点击“配对并启用自动刷新”，允许扩展连接该网关站点。配对码 10 分钟有效，只能使用一次。
5. 配对后，新的浏览器 Cookie 会同步到网关；每 15 分钟在已打开的目标工作区页面执行只读身份查询。
6. 浏览器和对应工作区标签页需保持打开并登录。此后的定时检查不刷新页面、不修改输入、不发送 Agent 消息。
7. 添加其他账号或工作区时分别导入、登录、配对。不同浏览器配置文件需分别配对。不支持隐身窗口。

边界与管理：
自动同步直接更新网关账号凭证，不会改写以前下载的 JSON。
Linear 若要求重新登录，仍需本人登录，不能保证永久有效。
网关会先向 Linear 验证身份，失效或不匹配的凭证不会覆盖原凭证。
扩展仅向自己填写并配对的网关发送凭证，不保存管理员密码。
服务端只保存配对码与同步令牌摘要；扩展本地保存的令牌只能更新相应账号，可在后台撤销。
扩展显示最近同步时间和错误；失败退避重试。电脑休眠或浏览器关闭会延迟或停止检查。
在后台撤销配对可阻止后续更新；扩展中停止并移除配对时会尽力撤销服务端授权。
旧 JSON 含登录 Cookie，仍应保存在受保护的位置。
